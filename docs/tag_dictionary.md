# Словарь тегов событий

ИИ размечает событие только кодами из этого словаря. У одного события может
быть несколько первичных тегов и несколько вторичных тегов. Первичные теги
описывают основной формат события. Вторичные теги описывают менее важные
уточнения и не должны перевешивать формат события.

## Первичные теги: формат события

| Код | Название |
|---|---|
| `concert` | Концерт |
| `theater` | Театр |
| `exhibition` | Выставка |
| `lecture` | Лекция |
| `cinema` | Кино |
| `sport` | Спорт |
| `masterclass` | Мастер-класс |
| `excursion` | Экскурсия |
| `festival` | Фестиваль |
| `standup` | Стендап |
| `party` | Вечеринка |
| `board_games` | Настольные игры |
| `quiz` | Квиз |
| `dance` | Танцы |
| `comedy` | Комедийное мероприятие |
| `market` | Маркет / ярмарка |
| `conference` | Конференция |
| `meetup` | Митап / встреча сообщества |
| `quest` | Квест |
| `food_event` | Гастрономическое мероприятие |

## Вторичные теги: менее важные уточнения

| Код | Название |
|---|---|
| `educational` | Познавательное |
| `creative` | Творческое |
| `cultural` | Культурное содержание |
| `active` | Активное участие |
| `relaxing` | Расслабляющий формат |
| `company_friendly` | Подходит для компании |
| `networking` | Нетворкинг |
| `interactive` | Интерактивное участие |
| `immersive` | Иммерсивное участие |
| `calm` | Спокойный формат |
| `loud` | Энергичный / громкий формат |
| `outdoors` | На открытом воздухе |
| `indoors` | В помещении |
| `evening` | Вечернее |
| `night` | Ночное |
| `family_friendly` | Подходит для семьи |
| `romantic` | Романтическая атмосфера |
| `small_group` | Небольшая группа |
| `large_group` | Большая группа |

Цена, бесплатность, возрастное ограничение, дата, время, место и расстояние
остаются отдельными полями и фильтрами. ИИ не должен превращать их в теги.

В рекомендациях вклад первичных тегов считается с коэффициентом `1.0`, а
вторичных — с коэффициентом `0.4`.

В онбординге показываем только часть словаря через `show_in_onboarding`, а
остальные используются для разметки и рекомендаций. При добавлении нового
тега он применяется только к новым карточкам, если отдельно не запустить
массовую переразметку.
