# Пользовательский flow

```text
/start
  → согласие на обработку данных («Не согласен» → «Вернуться к согласию»)
  → «Продолжить с Москвой»
  → «Создать профиль» или «Только афиша»

Профиль
  → имя → пол → возраст (18+) → описание (можно пропустить) → фото (можно пропустить)
  → минимум 3 интереса → меню

Афиша → «👍 Нравится» / «Не моё» / «Хочу пойти»
  → «Хочу пойти» → «Найти компанию» → анкеты людей на это событие
  → «👍 Пойти вместе» → взаимный лайк → мэтч → «Поделиться контактом» → подтверждение → контакт у второго человека
```

Меню `[Афиша] [Понравившиеся] [Мои планы] [Мой профиль]` прикреплено к карточкам и
системным сообщениям. На свободный текст бот отвечает «Сейчас здесь нужно выбрать
действие кнопкой ниже» и повторяет актуальные кнопки.

## События

Афиша показывает одно непросмотренное событие. После реакции исходная карточка
получает строку «✅ Нравится» или «✖️ Не моё», кнопки реакции с неё убираются,
а следующая карточка приходит новым сообщением.

- «👍 Нравится» сохраняет `like` и добавляет `+0.1` к тегам события.
- «Не моё» сохраняет `skip` без изменения весов.
- «Хочу пойти» создаёт план; вклад в теги — `+0.5` вместе с лайком.

Детские события (категория KudaGo `kids` или «для детей», «детский», «малыш» в названии)
в ленту и «Понравившиеся» не попадают; на уже запланированные детские события поиск
компании недоступен. Оценённые события в ленту не возвращаются. Показанные без реакции исключаются на 24 часа.
Если карточку не удалось отправить, она возвращается в начало очереди.

«Понравившиеся» — лайки без активного плана. «Мои планы» — активные планы; на карточке
плана есть «Найти компанию» или «Смотреть компанию», «Тебя лайкнули · N», «Отменить поход».
Отмена похода отзывает лайки и закрывает мэтчи по этому событию.

## Поиск компании

Поиск доступен только с активной анкетой. Гостю бот предлагает создать анкету; план
и веса сохраняются.

Показываются люди с активным планом на то же событие, которые тоже ищут компанию.
Исключаются своя анкета, блокировки и уже показанные люди. Показ сохраняется до отправки
анкеты; если отправка не удалась, показ откатывается.

- «👍 Пойти вместе» создаёт направленный интерес. На анкете появляется «👍 Лайк отправлен.
  Если интерес будет взаимным — сообщим о мэтче», затем приходит следующая анкета или
  «Других анкет для этого события пока нет».
- «Дальше» помечает анкету «➡️ Пропущено».
- Встречный интерес создаёт `match`.

Односторонние интересы раз в минуту собираются по получателю и событию: «На «{событие}»
с тобой хочет пойти N человек» с кнопкой «Посмотреть анкеты». Она показывает тех, кто
лайкнул и ждёт ответа, даже если их раньше пропустили.

## Мэтч и контакт

Оба участника получают «Есть мэтч 🎉» с кнопками «Поделиться контактом», «Пока не сейчас»
и меню. Контакт передаётся только добровольно:

1. «Поделиться контактом» → бот просит прислать текстом ссылку-приглашение MAX или другой
   контакт. Карточки контакта MAX не принимаются: номер телефона не передаётся без явного ввода.
2. Бот показывает контакт и спрашивает «Отправить этот контакт пользователю {имя}?».
3. «Да, отправить» → второй человек получает этот текст и кнопку
   «Поделиться своим контактом». Повторно отправить контакт по тому же мэтчу нельзя.

Пока бот ждёт контакт (не дольше часа), следующее сообщение пользователя считается
контактом, а не ответом на шаг анкеты. «Отмена» выходит из режима. Демо-анкетам
контакт не доставляется.

## Ошибки

Если действие не удалось (сбой MAX API или сети), бот отвечает «Не получилось выполнить
действие. Попробуй ещё раз — твой профиль и планы сохранены» с кнопками «Повторить» и «В меню».
